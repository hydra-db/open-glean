# Code of conduct

## Our pledge

We want Open Glean to be a project anyone can take part in. We treat every person
with respect, whatever their background or level of experience.

## Expected behaviour

- Be kind and patient.
- Accept feedback, and give it with care.
- Assume good intent, and ask before you judge.

## Unacceptable behaviour

- Harassment, insults, or personal attacks.
- Sharing someone's private information without their consent.
- Any conduct that would be out of place in a professional setting.

## Reporting

Report a problem to **conduct@hydradb.com**. Reports stay private. The
maintainers will review each one and respond.

## Scope

This applies in every project space, and in public spaces when a person
represents the project.

This code adapts the Contributor Covenant, version 2.1.
